## 🧭 Як влаштований довідник

### 1. Зручна структура (Sidebar & Breadcrumbs)
- **Бічна панель ліворуч**:
  - Містить швидкий пошуковий рядок по темах (`Фільтр тем...`).
  - Зручне дерево розділів: усі **4 великі частини** та **20 тематичних розділів**.
  - На кожній темі вказано бейдж із кількістю сторінок/блоків (наприклад, `19 с.`).
- **Хлібні крихти (Breadcrumbs)** вгорі сторінки чітко показують, де ви зараз знаходитесь.
- **Швидкий перехід**: унизу кожної теми розташовані великі картки переходу: `« Попередня тема` та `Наступна тема »`.
- **Мобільна адаптація**: на смартфонах меню тем ховається в зручну кнопку `☰ Меню тем`.

---

### 2. Інтерактивні фічі та блоки
- 📋 **Копіювання команд в 1 клік**:
  - Будь-яка серверна команда в тексті (наприклад, `/fract`, `/fspawnpoint`, `/bounty`, `/marry tp`) оформлена интерактивною плашкою.
  - Натисніть на команду — вона миттєво скопіюється в буфер обміну з повідомленням `✓ Скопійовано: /команда`.
- 📍 **Координати столиць**:
  - Координати спавнів рас (`📍 (-5000, -5000)`) підсвічені зеленими бейджами для зручної навігації на карті.
- 🎨 **Minecraft-кольори та стилі**:
  - Усі оригінальні кольорові коди гри (`§6` золото, `§a` зелений, `§c` червоний, `§e` жовтий тощо) автоматично підлаштовані під обрану тему.

### 3. Швидкі інструменти в шапці сайту
- 🔍 **Глобальний пошук (<kbd>Ctrl + K</kbd> або клавіша <kbd>/</kbd>)**:
  - Миттєвий пошук за будь-яким словом, механікою чи командою серед усіх матеріалів довідника.
  - Показує цитату з виділенням знайденого слова. Клік по результату одразу переносить вас на потрібну статтю.
- ⌘ **Каталог усіх команд (`⌘ Команди`)**:
  - Відкриває довідник із 51 командою сервера, розділеними на категорії: *Фракції*, *Влада & Лідер*, *Економіка*, *Шлюб*, *Тюрма & Розшук*, *Боси & Реліквії*.
  - Кожна команда має кнопку швидкого копіювання та детальний опис.
- 🛡️ **Порівняння 4 рас (`🛡️ Фракції`)**:
  - Зведена таблиця з характеристиками Ельфів, Дворфів, Кіцуне та Падших (зріст, перки, магічна зброя, вампіризм, мана).
- ⭐ **Закладки**:
  - Натискайте кнопку `⭐ Зберегти` на будь-якому блоці, щоб додати його до обраного. Закладки зберігаються у вашому браузері.
- 🎨 **Вибір теми**:
  - 🌙 **Темна** — за замовчуванням, зручна та контрастна для очей.
  - 📜 **Пергамент** — теплий вінтажний RPG-стиль.
  - ☀️ **Світла** — чистий мінімалістичний стиль документації.

## 🚀 Як опублікувати сайт на GitHub Pages

1. **Завантаження файлів на GitHub**:
   - Створіть репозиторій на GitHub (наприклад, `raifox-guide`).
   - Завантажте файл `index.html` та `README.md` у корінь репозиторію.
2. **Активація хостингу**:
   - Відкрийте репозиторій на GitHub і перейдіть у вкладку **Settings** (Налаштування).
   - У лівому меню виберіть розділ **Pages**.
   - У блоці **Build and deployment**:
     - **Source**: виберіть `Deploy from a branch`.
     - **Branch**: виберіть гілку `main` (або `master`) та директорію `/ (root)`.
     - Натисніть **Save**.
3. **Готово!**  
   Через 1–2 хвилини ваш сайт стане доступний усьому інтернету за адресою:  
   `https://<ваш-нікнейм>.github.io/<назва-репозиторію>/`

## 🔄 Як оновити сайт при змінах у моді

Якщо ви зміните тексти чи додасте нові команди у файлі `GuideBookManager.java`:

1. У терміналі / PowerShell у папці проєкту запустіть:
   ```powershell
   python build_site.py
   ```
2. Скрипт за 1 секунду автоматично згенерує свіжий `index.html`.
3. Завантажте оновлений `index.html` на GitHub!
