# ✦ Raifox: Season One — Офіційний Веб-Довідник ✦

> **Сучасна інтерактивна база знань для гравців сервера Raifox: Season One.**  
> Повний посібник із усіх правил, 4 рас, механік міста, босів, шлюбу, економіки, івентів та 56 серверних команд (`22` теми, `259` карток).

Сайт реалізовано як повністю автономний файл [`index.html`](index.html), що генерується скриптом [`build_site.py`](build_site.py) без зовнішніх залежностей, оптимізований для читання як онлайн-довідник (Wiki / Docs) та готовий до хостингу на **GitHub Pages**.

---

## 🧭 Як влаштований довідник

### 1. Зручна структура (Sidebar & Breadcrumbs)
- **Бічна панель ліворуч**:
  - Містить швидкий пошуковий рядок по темах (`Фільтр тем...`).
  - Дерево розділів: усі **4 великі частини** та **22 тематичні розділи** (від «1. Вступ та огляд» до фінального «22. Список команд сервера»).
  - На кожній темі вказано бейдж із кількістю сторінок/карток (наприклад, `20 с.`).
- **Хлібні крихти (Breadcrumbs)** вгорі сторінки показують поточну частину та тему.
- **Швидкий перехід**: унизу кожної теми розташовані картки переходу `« Попередня тема` та `Наступна тема »`.
- **Мобільна адаптація**: на смартфонах меню тем ховається в кнопку `☰ Меню тем`.

### 2. Інтерактивні фічі та блоки
- 📋 **Копіювання команд в 1 клік**:
  - Будь-яка серверна команда в тексті (наприклад, `/faction`, `/fspawnpoint`, `/bounty`, `/marry tp`) оформлена інтерактивною плашкою.
  - Натисніть на команду — вона миттєво скопіюється в буфер обміну з повідомленням `✓ Скопійовано: /команда`.
- 📍 **Координати столиць**:
  - Координати спавнів рас (наприклад, `📍 (-5000, -5000)`) підсвічені бейджами для зручної навігації.
- 🎨 **Minecraft-кольори та стилі**:
  - Усі кольорові коди гри (`§6` золото, `§a` зелений, `§c` червоний, `§e` жовтий тощо) адаптовані під обрану тему.

### 3. Швидкі інструменти в шапці сайту
- 🔍 **Глобальний пошук (<kbd>Ctrl + K</kbd> або клавіша <kbd>/</kbd>)**:
  - Пошук за будь-яким словом, механікою чи командою з фільтром по всіх 4 частинах довідника.
  - Показує фрагмент із підсвічуванням збігу та переводить безпосередньо на потрібну картку.
- ⌘ **Каталог усіх команд (`⌘ Команди`)**:
  - Відкриває довідник із **56 команд** сервера, поділених на 7 категорій: *Фракції*, *Влада & Лідер*, *Економіка & Резиденції*, *Шлюб*, *Тюрма & Розшук*, *Боси & Реліквії* та *Адмін & Івенти*.
  - Кожна команда містить опис, актуальні аліаси та кнопку швидкого копіювання.
- 🛡️ **Порівняння 4 рас (`🛡️ Фракції`)**:
  - Зведена картка ключових особливостей Ельфів (лук, самонаведення, 7 спецстріл, стелс, фермерство), Дворфів (бур `3х3` / Vein Miner, сокира-бумеранг, самонавідні ракети, золотий сет, ковальство), Кіцуне (`20%` ухилення, форма лисиці `/fox`, два мечі `+56.25%` і Тіньовий крок, ягоди та крадіжки) і Падших (`+2` броні й атаки, інверсія Візеру, удар щитом, Вартові Скалку, сканер і видобуток спавнерів).
- ⭐ **Закладки**:
  - Натискайте `⭐` на будь-якій картці, щоб зберегти її у `localStorage` браузера.
- 🎨 **Вибір теми**:
  - 🌙 **Темна** — за замовчуванням, контрастна тема.
  - 📜 **Пергамент** — теплий RPG-стиль.
  - ☀️ **Світла** — чистий стиль документації.

## 🚀 Як опублікувати сайт на GitHub Pages

1. **Завантаження файлів на GitHub**:
   - Створіть репозиторій на GitHub (наприклад, `raifox-guide`).
   - Завантажте файли [`index.html`](index.html) та [`README.md`](README.md) у корінь репозиторію.
2. **Активація хостингу**:
   - Відкрийте репозиторій на GitHub і перейдіть у вкладку **Settings** (Налаштування).
   - У лівому меню виберіть розділ **Pages**.
   - У блоці **Build and deployment**:
     - **Source**: виберіть `Deploy from a branch`.
     - **Branch**: виберіть гілку `main` (або `master`) та директорію `/ (root)`.
     - Натисніть **Save**.
3. **Готово!**  
   Через 1–2 хвилини сайт стане доступним за адресою:  
   `https://<ваш-нікнейм>.github.io/<назва-репозиторію>/`

## 🔄 Як оновити сайт при змінах

Контент веб-довідника, каталог команд (`commands_db`) та зведення фракцій формуються скриптом [`build_site.py`](build_site.py) (із використанням `TOPIC_OVERRIDES` та базових сторінок із [`GuideBookManager.java`](src/main/java/raifox/season/one/book/GuideBookManager.java)):

1. Внесіть потрібні зміни до [`build_site.py`](build_site.py).
2. У терміналі / PowerShell у корені проєкту запустіть:
   ```powershell
   python build_site.py
   ```
3. Скрипт згенерує оновлений [`index.html`](index.html) — завантажте його на GitHub.
