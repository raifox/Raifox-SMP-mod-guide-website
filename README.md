## 🧭 Як користуватися сайтом

### 1. Перемикання режимів перегляду
У верхній панелі (шапці сайту) доступні два режими:
- 📖 **Режим Книги (Interactive Tome)**:
  - Відтворює вигляд старовинного магічного фоліанта у шкіряній палітурці.
  - На великих екранах (ПК/ноутбуки) показує **розворот на 2 сторінки** (ліва та права), а на смартфонах автоматично перемикається на 1 сторінку.
  - **Гортання**: натискайте кнопки `◀ Попередня` / `Наступна ▶`, використовуйте клавіші стрілок на клавіатурі або просто свайпайте пальцем на сенсорному екрані.
  - **Швидкий перехід**: використовуйте повзунок унизу або введіть точний номер сторінки (від 1 до 228) і натисніть `Enter`.
  - **Звук гортання (🔊)**: у шапці є кнопка увімкнення/вимкнення реалістичного шелесту сторінок (синтезується браузером через Web Audio API, не потребує інтернету).
  - **Зміст частини**: на кожній сторінці вгорі є кнопка `« До змісту`, яка повертає вас до меню поточного розділу.

- 📑 **Режим Довідника (Wiki / Modern Docs)**:
  - Зручний формат документації для швидкого читання.
  - **Бічна панель ліворуч**: містить швидкий фільтр тем і дерево всіх 4 частин та 20 тем.
  - **Хлібні крихти (breadcrumbs)**: показують, у якій саме частині ви знаходитесь.
  - **Навігація між темами**: унизу кожної теми розташовані великі картки переходу до попередньої та наступної теми.
  - Кнопка `📖 Читати в Книзі` відкриває поточну тему в режимі фоліанта.

### 2. Інтерактивні фічі та блоки
- 📋 **Копіювання команд в один клік**:
  - Будь-яка команда в тексті (наприклад, `/fract`, `/fspawnpoint`, `/bounty`, `/marry tp`) є клікабельною кнопкою.
  - Натисніть на команду — вона миттєво скопіюється в буфер обміну, а на екрані з'явиться спливаюче сповіщення `✓ Скопійовано: /команда`.
- 📍 **Координати столиць**:
  - Координати спавнів рас (`📍 (-5000, -5000)`) підсвічені зеленими бейджами для зручної навігації на карті.
- 🎨 **Minecraft-кольори та стилі**:
  - Усі оригінальні кольорові коди гри (`§6` золото, `§a` зелений, `§c` червоний, `§e` жовтий тощо) автоматично підлаштовані під обрану тему.

### 3. Швидкі інструменти в шапці сайту
- 🔍 **Глобальний пошук (<kbd>Ctrl + K</kbd> або клавіша <kbd>/</kbd>)**:
  - Миттєвий пошук за будь-яким словом, механікою чи командою серед усіх 228 сторінок.
  - Показує цитату з виділенням знайденого слова. Клік по результату одразу переносить вас на потрібну сторінку.
- ⌘ **Каталог усіх команд (`⌘ Команди`)**:
  - Відкриває модальне вікно з 51 командою сервера, розділеними на категорії: *Фракції*, *Влада & Лідер*, *Економіка*, *Шлюб*, *Тюрма & Розшук*, *Боси & Реліквії*.
  - Кожна команда має кнопку швидкого копіювання та детальний опис.
- 🛡️ **Порівняння 4 рас (`🛡️ Фракції`)**:
  - Зведена таблиця з характеристиками Ельфів, Дворфів, Кіцуне та Падших (зріст, перки, магічна зброя, вампіризм, мана).
- ⭐ **Закладки**:
  - Натискайте на червону стрічку-закладку на книзі або іконку зірочки `⭐`, щоб додати сторінку до обраного. Закладки зберігаються у вашому браузері.
- 🎨 **Вибір теми**:
  - 📜 **Пергамент** — теплий вінтажний RPG-стиль для читання книги.
  - 🌙 **Темна (Обсидіан)** — темна тема, зручна для нічної гри.
  - ☀️ **Світла** — чистий мінімалістичний стиль документації.

## 🚀 Як опублікувати сайт на GitHub Pages

1. **Завантаження файлів на GitHub**:
   - Створіть репозиторій на GitHub (наприклад, `raifox-guide`).
   - Завантажте файл `index.html` та `README.md` у корінь репозиторію.
2. **Активація хостингу**:
   - Відкрийте репозиторій на GitHub і перейдіть у вкладку **Settings** (Налаштування).
   - У лівому меню виберіть розділ **Pages**.
   - У блоці **Build and deployment**:
     - **Source**: виберіть `Deploy from a branch`.
     - **Branch**: виберіть гілку `main` (або `master`) та директорію `/ (root)`.
     - Натисніть **Save**.
3. **Готово!**  
   Через 1–2 хвилини ваш сайт стане доступний усьому інтернету за адресою:  
   `https://<ваш-нікнейм>.github.io/<назва-репозиторію>/`

## 🔄 Як оновити сайт при змінах у моді

Якщо ви зміните тексти, команди чи додасте нові сторінки у файлі `GuideBookManager.java`, оновити сайт дуже просто:

1. Переконайтеся, що на ПК встановлено Python 3.
2. У терміналі / PowerShell у папці проєкту запустіть:
   ```powershell
   python build_site.py
   ```
3. Скрипт за 1 секунду автоматично перечитає `GuideBookManager.java` та згенерує новий свіжий `index.html`.
4. Завантажте оновлений `index.html` на GitHub — сайт оновиться автоматично!
